# Dynamics Aero

Gestão à vista de aeronaves particulares, no visual do cockpit TSE.

A operação de demonstração é a Ventura Aviação: três aeronaves, três sócios, itinerários, despesas, hangar, pessoal, manutenção e rateio. Os números fecham entre si. Ainda não há banco de dados.

```bash
npm run dev
```

Abra [http://localhost:3000](http://localhost:3000).
